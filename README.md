# Expense Tracker

Pre-build research and requirements for a fast, trustworthy, feature-rich expense tracker.

- [`docs/PRODUCT_CONTEXT.md`](docs/PRODUCT_CONTEXT.md): vision, personas, domain model, functional and non-functional requirements, open decisions, traceability from pain points to requirements.
- [`docs/ROADMAP.md`](docs/ROADMAP.md): delivery phases (Android first, then iOS) with scope, exit criteria and a coverage table assigning every requirement to a phase.
- [`docs/MARKET_RESEARCH.md`](docs/MARKET_RESEARCH.md): market map, ranked pain-point taxonomy (`PP-xx`), what users love, wishlist, India and technology facts.
- [`docs/research/`](docs/research/): full cited reports (global budgeters, manual trackers, India, shared expenses, review mining, technology).
